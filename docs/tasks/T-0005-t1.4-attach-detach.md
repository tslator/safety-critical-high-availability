## Scope

Implement named `/dev/shm` attach/detach for a `SharedRegion` with re-attachment
support and stale-object rejection.

## Deliverables

- `shared_region.hpp` create-or-open attach API: exact compiled-in region size,
  `mmap` + `madvise` (`MADV_DONTFORK`, optional `MADV_HUGEPAGE`), in-place
  `initialize`; existing-vs-new detected by identity word and expected size.
- Detach via `munmap` (never truncate while peers may be attached); a separate
  explicitly destructive reset path for tests only.
- Explicit error codes from the attach path (no exceptions).
- `shm_attach_test.cpp`: two processes/threads sharing one region; stale or
  wrong-size object rejected.

## Acceptance Criteria

- Attach/detach round-trips against a named region.
- Stale-object rejection on wrong magic/size.
- Gate G1.4 passes (attach tests green, including stale rejection).
