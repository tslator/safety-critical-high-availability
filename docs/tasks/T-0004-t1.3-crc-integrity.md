## Scope

Add CRC integrity and corruption detection to `safety_crit::shared_memory` on
top of the merged T1.2 protocol: per-slot CRC-32C, a corruption-skip path in
`try_pop`, a corruption counter, and a whole-region integrity word — without
weakening any Tier 1 hot-path property.

## Deliverables

- `integrity.hpp` / `src/integrity.cpp` (CRC-32C: SSE4.2 intrinsics when
  compiled with `__SSE4_2__`, compile-time table fallback otherwise).
- In-cell per-slot CRC: `Cell` = `{ sequence @0, payload[52] @8, crc @60 }`;
  `kDefaultSlotBytes` 56 → 52; `kRegionVersion` 2 → 3.
- `try_pop` corruption path: on mismatch, release the slot, increment a
  per-ring corruption counter, return `false` without copying out.
- Region-level `push(...)` commit wrapper refreshing `integrity_word` via a CAS
  loop with quiescent convergence.
- `shared-memory/tests/integrity_test.cpp`.

## Acceptance Criteria

- Known CRC vectors pinned (incl. `crc32c("123456789") = 0xE3069283`).
- Corrupting one committed slot: pop returns `false`, `corruption_count() == 1`,
  all other messages intact and ordered.
- Region integrity word agrees at quiescence; one flipped header byte disagrees.
- Hot path stays allocation-, syscall-, exception-, and mutex-free.
