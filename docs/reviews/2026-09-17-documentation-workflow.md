# D-2026-09-17-001: Documentation Discussion Records

- Date: 2026-09-17
- Status: Accepted
- Related decision: [DEC-0003](../decisions/0003-documentation-discussion-records.md)
- Resulting task: [T-0001](../tasks/T-0001-documentation-index.md)

## Question

How should project discussions become durable, assignable engineering work
without committing raw conversation transcripts?

## Findings

The repository needs a current status page, clearer documentation navigation,
and a traceable path from review findings to implementation and evidence.

## Alternatives Considered

- Preserve complete chat transcripts: rejected because they are noisy and hard
to maintain.
- Introduce a database or issue-tracker integration: deferred until Markdown
records prove insufficient.

## Result

Use concise discussion/review records, decision records, task records, and
evidence records connected by stable IDs and Markdown links.
